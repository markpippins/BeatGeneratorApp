# Phase A API Realignment Delta Matrix (Initial)

Date: 2026-05-03
Author: OpenCode

Scope
- Initial deltas to guide Phase A API realignment on core-model surfaces used by beatgen-core.

- Delta 1: InstrumentWrapper alias
- Surface: InstrumentWrapper.isDefault (Boolean field) vs isDefaultInstrument() alias.
- Core-model surface: isDefault field with an isDefault() getter generated by Lombok (or getIsDefault when used in code paths).
- Gap: Needs explicit alias for tooling that expects a clearly named accessor.
- Resolution: Provide isDefaultInstrument() alias on InstrumentWrapper (added).
- Rationale: Improve compatibility with UI/tools while preserving semantics.

- Delta 2: Phase A surface references for per-tick evaluation
- Surface: Mutators in Player.initialize path (setName, setSession, setInstrument, setAllowedControlMessages).
- Core-model surface: Public setters exist; verify signature compatibility with beatgen-core calls.
- Gap: Validate signatures to match usage; plan minimal non-breaking wrappers if needed.
- Resolution: Track these in Milestone 1 inventory and plan patches for Milestone 2.

- Delta 3: Command surface alignment
- Surface: Command.getCommand() and Command.getData() usage in IBusListener and CommandBus.
- Core-model surface: Command class exposes command and data fields via Lombok.
- Gap/Resolution: Align usage; document deviations and plan patches if needed.

Notes
